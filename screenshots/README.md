# Screenshots

The original report included screenshots of SQL query result tables (donation totals by gender, by state, by job field, by donation-size threshold, by car brand, and the second-language cross-tabulation).

Those images have not been added to this repository yet.

## To add them

1. Export or screenshot the relevant tables from `Education_For_All_Donor_Insights_Report.docx` (or the original PDF, if you still have it).
2. Save them here using descriptive filenames, for example:
   - `donation-by-gender.png`
   - `donation-by-state.png`
   - `donation-by-frequency.png`
   - `donation-by-job-field.png`
   - `donation-threshold-split.png`
   - `donation-by-car.png`
   - `second-language-by-frequency.png`
3. Reference them from the main `README.md` under **Dashboard preview** once added.
